## To try by hand on real Plaxis

1. [ ] Start Plaxis ProMax from Plaxis (Expert > Python > Run script > "Plaxis ProMax.py"): the window opens and its header names the project.
2. [ ] Ask "What is in this project?": the answer names the units, layers, structures and phases of the project that is open.
3. [ ] Attach a borehole log (PDF or Excel) and ask for the soil model: it lists the layers it read, asks before it builds, and the boreholes appear in Plaxis.
4. [ ] Ask for a change (a new phase): a brief card shows first; Run this makes the change and Plaxis shows the phase.
5. [ ] Decline an approval card once: nothing changes in Plaxis and the chat asks what you want instead.
6. [ ] Ask for two separate things at once in a chat With coordinator: two job cards show, and their steps in Plaxis take turns.
7. [ ] Calculate a small project one phase at a time: each phase's result is reported and the project is saved between phases.
8. [ ] Ask for results into Excel and a Word report: both files open from their cards in the chat.
9. [ ] Switch the Phone on and send a message from the phone: it reaches this project's chat, and the reply reaches the phone.
10. [ ] Press Shrink chat in a long chat, then ask a follow-up: the chat still knows what was done.
11. [ ] Close the window while a chat is open and start again: the chat is in the history and carries on.

If a step fails, Settings > Report bug sends this PC's details and this chat to the developer.
