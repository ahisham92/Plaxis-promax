# Plaxis ProMax bug log

One line per bug, newest at the bottom. Status: **Open** → **Fixed in x.y (please check)** → **Confirmed** once the
reporter has checked the fix.

Plaxis ProMax downloads this file at every update check (when the window opens, then hourly) into
Documents\Plaxis ProMax\Bugs\Bug log.md and adds a "Not sent yet" list of the bug report zips on that PC that this log
doesn't cover yet: a report counts as sent once a row below names it by the date and time in its zip name
("Bug report yyyy-MM-dd HHmm.zip"). Never write project, client or person names here: this repository is public.
