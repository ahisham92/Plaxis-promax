The Plaxis-native look.

- The Modeller and the Viewer are laid out like PLAXIS Input and Output: the menu in Plaxis's order, one row of tools with the mode tabs as arrows, the Phases, Selection and Model explorers on the left, a side toolbar beside the drawing, and a command line under it. In the Viewer, the phase and the plot are lists in the toolbar and the legend is on the left of the plot, as in Output.
- The ProMax panel: the chat docked in the Modeller and the Viewer like one more explorer. It shows each step the chat takes and its answers, lets you Allow or Don't allow when the chat asks, and sends what you type to the chat. The command line lists the same steps (ProMax steps) and the messages of the checks and runs (Session).
- The chat window has square, Plaxis-like corners, a grey panel head and tables with grid lines. When Plaxis is open it stands slim beside the Plaxis window, as tall as it; the ⋯ menu's Beside Plaxis does it again. Plaxis itself is never moved.
- Only our own mark and icons: no Bentley logos, icons or artwork.
