The Modeller and the Viewer, with no Plaxis licence.

- Plaxis ProMax Modeller: its own window, from its own shortcut, to build a PLAXIS 2D or 3D model in the five modes of Plaxis Input (soil, structures, mesh, flow conditions, staged construction), with materials, boreholes, structures, loads, water levels and phases. The chat can read and change the same model. No Plaxis is open and no licence is used.
- Calculate in Plaxis: the only step that takes a licence. It opens Plaxis, builds, meshes and calculates the model, copies the results into a results file and closes Plaxis again, so the licence is free for others. It can also export the build as a script to run in Plaxis yourself.
- Plaxis ProMax Viewer: the views of Plaxis Output with no Plaxis: deformed mesh, displacements, stresses, pore pressures, plastic points, plate and anchor forces, cross sections, curves, tables, in 2D and 3D. Pictures, CSV tables, and one HTML file to send to a reviewer.
- New chat tools: open_modeller, modeller_model, modeller_edit, modeller_check, modeller_save, calculate_in_plaxis (always asks, because it takes a licence), open_results_viewer and read_results.

Tested against a stand-in Plaxis only: the Plaxis property names the builder uses, and the result names it reads, still need the field test on real PLAXIS 2D and 3D.
